# 把 State Coordination 理解透：逐步学习与复述

这份指南用已有文件、具体例子和反向提问，帮助研究者理解每一个判断是怎样来的。完成阅读不等于已经掌握；每一步都需要用自己的话解释，并指出证据停在哪里。建议一次完成一节，再接受追问。

[研究脉络](research_story.zh-CN.md) · [时间线](project_history.md) · [结果与方法](../research/2026-09-20/README.md)

## 第一步：把自己的问题说清楚

先只谈一个疑问：为什么有些制度和政策留下的条件，在环境改变以后仍然能帮助人和企业发展？

你的起点涉及亚洲国家的制度顺序。先把其中三个命题分开：

| 命题 | 需要什么证据 | 当前是否回答 |
|---|---|---|
| 一些成功案例在民主化之前已经具有较强国家能力 | 历史时间线与可靠测量 | 可以做个案描述，但不能只挑成功案例 |
| 转型前能力较高与之后增长较快相关 | 明确样本、变量和比较 | 九月分析提供探索性关联 |
| 威权时期建立能力是繁荣的必要前提 | 明确的必要性定义、范围和对不同发展路径的系统考察；因果解释还需要反事实依据 | 当前没有回答 |

练习：用三句话分别说“我好奇什么”“我猜测什么”“我目前实际检验了什么”。避免用“研究证明”把三句连成一句。

通过标准：能解释为什么几个成功案例不足以支持必要性；能说出什么观察会让自己的初始假设变弱。必要性命题在定义和范围清楚时可被一个有效反例推翻，但一个看似例外的国家还需要核实其概念与历史。

## 第二步：从一项具体安排理解“能力”与“优势”

下面是虚构例子，不是项目结果：政府出资建立检测中心。大企业可能先使用它；新企业如果后来也能以可承担的费用使用，它可能成为较广泛的生产条件。如果只有指定企业能进入，同一设施也可能巩固既有优势。这两种情况还可能同时存在。

现在看仓库里的真实编码记录：[1994 年汽车文件](../data/real_coded_passages_automobiles_1994.csv)，source_id 为 SRC_AUTO_1994_006，涉及国家级研究、试验和检测机构的建设安排。

| 判断 | 当前材料能否支持 | 还需什么 |
|---|---|---|
| 政策文字提出建设有关机构 | 可据已保存摘录追查；原文来源仍需加强 | 更可靠的官方全文和条款位置 |
| 机构后来建成并运行 | 摘录不足 | 建设、运营或机构档案 |
| 新企业可实际获得服务 | 摘录不足 | 资格、费用、排队和实际服务对象 |
| 获得服务改善了创新或进入 | 摘录不足 | 企业结果、比较对象和替代解释 |

现有 notes 将该安排解释为 shared institution-building，但文字本身并没有确认所有企业都能使用。把这里看作需要复核的解释，而不是已经证明的开放准入。

再看 SRC_AUTO_1994_012 的新项目审批限制：它可以提供正式进入限制的线索，不能单靠它断言既有企业实际获得了多少利益。现有 notes 中较强的机制语言仍需结果证据。

练习：分别用一句话说明“文件写了什么”“我怎样理解它”“我还不知道什么”。

通过标准：能把政策意图、正式规则、实际执行和效果分开；不把 accepted 或 high confidence 当作外部验证。

## 第三步：用一个国家重建数字

例子：DDCG 在本分析中将韩国转型年编码为 1988。这里采用数据集定义，不表示历史转型只有一个日期。

1. 能力取 1983–1987 五年的均值。
2. 基线收入来自 1987 年。
3. 十年增长比较 1987 与 1997；二十年比较 1987 与 2007。
4. 年均对数增长 = 100 × [ln(期末人均 GDP) − ln(基线人均 GDP)] ÷ 年数。
5. 每个符合条件的国家产生一条转型记录；57 个国家不是 57 个随机分配的实验对象。

虚构算术例子：人均 GDP 从 10,000 变为 12,000，用十年计算的年均对数增长约为 1.82%；通常的复合年增长率约为 1.84%。本项目使用前者，不能混用名称。

查看 [主样本](../research/2026-09-20/main_transition_sample.csv) 中韩国的一行，再对照 [计算方法](../research/2026-09-20/README.md#data-and-sample-construction)。国家能力的一标准差在预先固定的 71 个转型参考样本中约为 0.694 个原始单位，它不是“政府能力提高了某个百分比”。

练习：解释为什么先取五年均值；指出五年是需要论证的分析选择。说明它能平滑年度波动，但无法排除历史混杂或测量误差。

通过标准：能画出时间窗口并解释单位，不把 1.26 个百分点讲成 GDP 水平提高 1.26%。

## 第四步：说清楚回归实际比较什么

当前主模型的关系可以写成：

后续平均增长 = 常数 + 能力系数 × 转型前能力 + 初始收入项 + 转型年份项 + 未解释部分。

能力系数描述：在这个线性模型里调整初始收入与转型年份后，能力不同的国家，其增长如何共同变化。这种调整没有让国家在教育、历史、战争或国际支持上自动变得相同。

如果较好的教育同时帮助建立行政能力并推动之后增长，能力系数可能包含教育相关的差异。如果早期能力已经影响了初始收入，控制收入也可能移除你希望研究的一部分发展路径。控制变量应跟随问题和时间关系选择。

练习：画出“教育 → 国家能力”和“教育 → 后续增长”；再解释为什么“能力发生在增长之前”仍不足以证明因果。

通过标准：能指出至少一个具体替代解释，并说明 HC3 标准误处理的是误差方差问题，不负责解决遗漏变量或样本选择。

## 第五步：读懂结果，也能解释不确定性

原定主要分析是十年 DDCG：估计约 +0.63，95% 区间约 −0.44 至 +1.70。它既不证明没有关联，也不支持精确、确定的正向结论。

后续世界银行二十年共同样本：约 +1.26，区间约 +0.43 至 +2.09。需要同时记住它是次要窗口、来源诊断的一部分，样本与主要十年分析不同。

更公平的时间窗口比较固定同一组 57 个国家和同一世界银行来源：十年约 +1.18，二十年约 +1.26。直接比较两者差异，约为 +0.08，区间约 −0.63 至 +0.79。这里没有清楚证据表明两个系数不同，也没有证明它们完全相等。

逐一排除国家后结果仍为正，只回答“是否由某一个国家驱动”。它没有回答“是否所有国家都存在同样的遗漏因素”。更换数据源也不等于完全独立复制，因为来源可能使用相同底层统计。

练习：对“二十年显著、十年不显著，所以制度需要二十年才发挥作用”作出纠正。用自己的话解释置信区间，不把它当作在所有测量和模型假设之外都成立的保证。

通过标准：能区分数值更大、估计更精确、两个系数有证据不同、具有因果意义这四件事。

## 第六步：理解几条研究线怎样相关

~~~mermaid
flowchart TD
    A[制度怎样留下可持续的发展条件] --> B[三月底的制度顺序假设]
    B --> C[正文日期为四月的韩国机制方案]
    C --> D[中国 WTO 政策测量试点]
    B --> E[九月跨国描述性分析]
    C --> F[能力可被谁使用与既有优势]
    D --> F
~~~

箭头表示研究思路或任务之间的关系，不表示已经识别出的因果路径。四月机制方案已有能力与既有优势的区分；中国 WTO 改变了研究场景；九月回归是另一分析层次。

练习：分别说出两条实证工作的分析单位、变化事件、结果变量。解释为什么跨国 GDP 关联不能验证一个政策编码分数，也不能证明新企业获得了检测服务。

通过标准：能讲清延续的研究动机，也承认更换场景后不能回答的原始问题。

## 第七步：形成自己的两分钟说明，再接受追问

先不看 [研究脉络中的示范](research_story.zh-CN.md#7-当前可以怎样介绍这项研究)，依次说明：

1. 什么具体疑问使你在三月底开始做它？
2. 什么材料或困难让问题变得更具体？
3. 你现在实际完成了哪两类工作？
4. 哪个结果最值得继续追查，哪个限制最重要？
5. 下一项可完成的小任务是什么，它会改变哪个判断？

追问清单：为什么是这些国家？“能力”是什么？为什么看 GDP？为什么更换到中国 WTO？如果结果不符合最初猜想，你会怎样改？哪些步骤有 AI 协助，哪些你已经能够自行解释？

自评只用三种状态：能自行解释并定位依据；需要看材料才能解释；尚不能解释。记录具体卡点，不按术语数量或语言流畅度打分。示范答案不能证明研究者已经掌握方法。

## 最小的下一项研究任务

完成一张政策证据卡：原文与来源位置 → 现有编码 → 可核实的受益资格 → 尚缺的使用证据 → 可以比较的结果。先完成一项安排，再决定扩展范围。一次只增加足以改变一个判断的材料。
