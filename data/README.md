# Data folder

Two kinds of files: synthetic demo data used to illustrate the workflow, and real passages
coded from primary policy documents.

---

## Synthetic demo data (`demo_*`)

Built around the South Korea 1987 setting (see the repository README on empirical
settings). Generated by `scripts/00_` and `scripts/01_`.

| File | Contents |
|---|---|
| `demo_coded_passages.csv` | Synthetic passage-level scores across the four support dimensions |
| `demo_sector_year.csv` | Synthetic sector-year outcomes before and after 1987 |
| `demo_support_index.csv` | Sector-level index generated from the above |

**These are for workflow demonstration only and carry no substantive interpretation.**

---

## Real coded data (`real_*`)

All real data comes from the China / 2001 WTO accession setting. Every passage carries
`passage_excerpt`, `coder_id`, `confidence`, and `review_status`. Allocation-dimension rows
also carry `direction` (`protective` / `compressive` / `neutral`) — see
`docs/coding_rubric.md`. Coding used AI-assisted first-pass drafting with human review; see
`prompt_log_automobiles_2026-07-19.md` in this folder for a completed run log.

### Coverage

| Sector | Year | Document | Passages | Relative to accession |
|---|---|---|---|---|
| Automobiles | 1994 | 汽车工业产业政策 | 13 | Pre |
| Automobiles | 1996 | 九五纲要, automotive section | 3 | Pre |
| Automobiles | 2004 | 汽车产业发展政策, State Council/NDRC Order No. 8 | 9 | Post |
| Textiles | 1998 | 国发〔1998〕2号 | 8 | Pre |

The pre-accession batches (1994, 1996, 1998) are the inputs to the support index. The 2004
batch is not — it documents institutional continuity across the transition (see repository
README).

### Source strength

Provenance is uneven across batches and is recorded rather than smoothed over:

| Batch | Verification | Strength |
|---|---|---|
| Automobiles 2004 | Official State Council Gazette text at gov.cn | Strong |
| Automobiles 1996 | Official NDRC PDF of the Ninth Five-Year Plan | Strong |
| Textiles 1998 | Legal-database full text, cross-checked against provincial gazette forward and MOFCOM reprint | Adequate |
| Automobiles 1994 | Archived press reprint (Sina), verified against researcher-supplied screenshots of the primary text | **Weakest — replacement with an official source is an open task** |

### Known gaps

- Sector coverage is imbalanced: three automotive documents against one textile document. A post-accession textile document is missing and would mirror the 2004 automotive batch.

## A note on what belongs in a public repository

Raw archival materials should be stored separately where copyright or access restrictions
apply. This repository holds metadata, codebooks, and replication-safe excerpts rather than
full source text.
